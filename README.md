# Simpletron Emulator (C)

This project is my implementation of the "Simpletron" virtual machine,
an educational exercise from the book "C How to Program".

## What I learned
- Low-level instruction execution (fetch-decode-execute cycle)
- Memory simulation
- Basic CPU architecture concepts

## Features
- Instruction set implementation (READ, WRITE, LOAD, etc.)
- Error handling (division by zero, overflow)
- Memory dump debugging

## Future improvements
- File-based program loading
- Step-by-step execution mode
- Instruction assembler
